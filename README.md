## ✨ The Vision

Most financial calculators are boring, gray spreadsheets. This project reimagines personal finance as a premium, Apple-like experience. Built with native web technologies, it uses advanced CSS `backdrop-filter` techniques, buttery-smooth micro-animations, and dynamic mathematical engines to make planning your yearly income actually *fun*.

<br>

## 🚀 Features

- 🔮 **True Glassmorphism:** Stunning frosted glass design with dynamic gradient orbs that react and blend behind your data.
- 📊 **Intelligent Allocation Algorithms:**
  - **Equal Split:** Automatically divide your remaining goal evenly across 12 months.
  - **Progressive Growth:** Start slow and automatically ramp up your income targets by 10% each month as you build momentum.
  - **Manual Control:** Take absolute control and punch in custom targets for any given month.
- 📱 **Flawless Responsiveness:** Bulletproof CSS Flexbox/Grid architecture ensures perfect, unbroken layouts whether you're on a 4K monitor or an old iPhone.
- 🛡️ **Math-Proof UI:** Advanced number formatting that intelligently abbreviates massive numbers to `Cr` and `L`, preventing layout blowouts.
- 🥚 **Ludicrous Mode:** Try typing in an income greater than ₹10 Crores and watch the app's Easter eggs activate!

<br>

## 🛠️ Zero-Build Tech Stack

No node_modules. No build steps. No compilation. Just pure, highly-optimized web standards.

| Technology | Purpose |
| :--- | :--- |
| **HTML5** | Semantic, accessible DOM structure. |
| **CSS3** | Native CSS Variables, `backdrop-filter`, and hardware-accelerated animations. |
| **Vanilla JS** | Lightweight, zero-dependency state management and DOM manipulation. |
| **Chart.js** | Beautiful, animated canvas charts (via CDN). |

<br>

## 🎨 Design Philosophy

* **Hardware Acceleration:** Uses modern CSS isolation to ensure heavy blurs don't exhaust mobile GPU memory.
* **Typographic Scale:** Built on the `Inter` font family for maximum legibility of financial data.
* **Bulletproof Inputs:** Every layout container is mathematically locked to prevent flex-blowouts when users input edge-case data.
